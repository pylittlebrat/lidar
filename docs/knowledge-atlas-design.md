# 知识星图设计说明

## 产品目标

把图谱变成从方向发现技术线索的探索入口。用户可以完成三个动作：辨认方向分布、进入一个方向阅读项目、沿副标签发现相邻方向。

旧图的问题来自结构：所有类别挤在同一个环上，每个节点都使用高饱和大光晕；放大只改变尺寸；多标签情报重复绘制造成统计膨胀。新的视觉层级依次为星系轮廓、方向名、重点星、具体情报。

## 四个视角的取舍

| 视角 | 改动 | 验收方式 |
| --- | --- | --- |
| 产品 | 全景 → 星系 → 情报；每条情报只有一个主归属 | 全景显示唯一情报数；详情能看到所有方向标签 |
| 用户 | 点击方向自动靠近；搜索可定位；侧栏可直接阅读；返回全景始终可用 | 进入星系、搜索、读摘要、跳转副标签、返回均可完成 |
| UI | 统计收进底栏，筛选默认折叠，近景航线减弱；固定屏幕字号并避让文本 | 标签不随相机无限增大；详情区优先呈现情报，航线列表可展开 |
| 美术 | 深蓝空间、有色彩层次的自由星团、局部星云和细星尘、少量重点亮星 | 各星系的疏密与轮廓不同，避免重复的 S 形和圆环排布 |

## 数据规则

- `belongs_to` 的逐标签权重决定主归属；有 `category_scores` 时优先采用该分值体系，未提供的类别视为 0。平分时保留分类顺序。
- 现有数据库没有逐标签置信分，因此真实数据按原分类首标签归属。规则分类器返回按命中数排序的分类；历史模型分类顺序不保证置信度排序。情报相关度决定星球大小、亮度与阅读排序，不充当标签分值。
- 各星系的情报使用同一套评分尺寸：同一视距下，0–100 分严格递增，较高分段的大小差异更明显。星系核心、悬停和选中不额外放大实体；强调状态使用光晕和外圈。3D 透视缩放有界，深度放大时星体也随之变大，最大半径不超过 16 像素；未评分条目保留小型可见星点。点击区域和标题间距随实际星球尺寸调整。
- 星系内部按评分由高到低安排离中心的距离，最高分情报位于中心。采用各星系内部的评分排序连续分配半径，同分情报可在所属区间自然散开；方向仍来自自由星团采样，不形成固定圆环。距离按完整 XYZ 向量归一化，保证评分更高的情报在真实三维空间中更靠近中心。未评分排在有效 0 分之外；完全没有评分的星系保留自由分布。各星系的半径不同，不跨星系比较绝对距离。
- 副标签不复制星点，仍计入共现航线和关联阅读列表。只有副标签的方向也保留入口，并标注关联数量。
- 航线表示同一条情报中的方向共现，不代表因果关系、依赖关系或实际合作。全景默认显示最强的少量航线；悬停或选中时展开相关航线，也可主动显示全部。
- 页面默认展示全库：全部时间、全部评分、全部项目，不做 700 条数量截断，尚未分析的条目也会纳入。没有有效方向标签的条目进入“待分类”星系，未评分与 0 分区分显示。所有条目都保留为可搜索星点，侧栏分页展开；分页仅影响阅读列表，不删减图中的星点。页首与底栏同时标明当前展示数量和全库数量。
- 全景显示所有真实星点，放大后逐步显示标题。真实星点有最小可见尺寸；装饰星尘的亮度和大小更低，避免混淆实际情报规模。
- 星系位置使用稳定的语义锚点并避碰，属于探索布局；距离不是关系强度的统计刻度。装饰性星尘不代表额外情报，只有较亮星点可被选中。

## 实现与交互

页面统一采用 3D 星系，原来的“星系图 / 我的项目 / 技术方向全景 / 全部情报网络”切换移除。项目视角作为筛选项保留，筛选后仍使用同一个星系组件。

星系中心、节点和星尘均有 XYZ 坐标；自由星团带有体积厚度，不同星系采用不同朝向和深度。透视投影计算近大远小，按相机深度排序粒子，并用远处的亮度衰减区分前后。跨方向航线也是空间曲线。文字和详情面板保持正向，不随场景倾斜。

星系采用更饱满的自由星团：中心较密、外围疏开，每个方向包含不同位置、大小的局部聚集，没有固定双旋臂。星点和装饰星尘沿同一空间分布采样，保持自然的疏密和不同轮廓。预生成的透明星云纹理采用类别色，只提供柔和的局部雾光和细密背景星光，避免强白亮核盖过真实星点；纹理只在初始化时生成，不加载外部图片，也不增加情报数量或点击目标。全景默认的少量关系线降低对比度，进入和悬停时再强调关联。

3D 几何与相机通过本地 Canvas 2D 投影绘制，不依赖 WebGL、第三方网络资产或新增运行依赖。布局与星尘采用固定种子；拖拽默认旋转，Shift / 右键拖拽或“平移”按钮移动视角，滚轮朝鼠标位置推进。聚焦后最近视距由星系半径的 1.65 倍降至 0.42 倍（保留 60 世界单位下限），支持深入星团观察；桌面也可收起详情栏以扩大画布。“自动环绕”需要主动开启，交互或进入星系时停止，场景不可见时暂停；系统启用减少动态效果时禁用自动环绕。

镜头进入星系与返回全景使用平滑过渡，并遵循减少动态效果设置；非交互时不持续运行动画。键盘方向键旋转，Shift + 方向键平移；保留方向列表、搜索、缩放按钮、详情阅读和 Esc 返回。星系内距中心的远近表示评分排序；星系之间的距离、相机深度不代表技术重要度。

几何回归测试：`node --test tests/galaxy-space.test.cjs`，覆盖星团密度与体积、透视、深度缩放边界、鼠标位置缩放锚定、轨道旋转、近裁剪面、坐标变换和宽窄视口适配。页面测试验证单入口与项目筛选继续使用星系组件。

内容通过文本转义显示，只允许 HTTP/HTTPS 原文链接；嵌入数据对脚本结束标签进行转义。完整标题和摘要从图数据传递到详情，避免在存入图结构时截断。

直接入口：`http://localhost:8501/?view=knowledge`。
